# 阶段 1：当前状态

> 本页只写**当前状态**，随版本更新直接改写，不再追加流水账。阶段 1 开发期的完整原始记录已归档到 [phase-1-history.md](phase-1-history.md)，各专题的权威说明见文末链接。

## 定位

Duet 是 AI 时代的学习工作台：在 AI 的帮助下更高效地学懂一个项目（读项目轨道），并做出一个自己完全掌握的项目（做项目轨道）。学习机制建在语言无关的层面——Git diff、任务节点、讨论与笔记——目标项目不限编程语言。定位与学习方法见 [LEARNING.md](../LEARNING.md)。

## 已交付能力（截至 v0.1.0）

- **任务与节点**：只读讨论（`i`）先行，计划经宿主校验（字段、依赖、环）后保存；`s` 明确授权才逐节点在隔离 worktree 编码；执行状态、验收状态、人工批准三者分离，批准绑定节点检查点，无文件交付记 NoChanges 并暂停后续。
- **不可变审阅**：预览与交付均为固定 Git 快照；审核按节点筛选文件；统一的内嵌 Helix 会话服务审核与项目视图（同一进程、受管文件切换、选区上下文只读 AI 讨论、草稿保存后可发布新固定修订）；原生审核后端可显式选用。
- **验证 Runner（首版）**：`v` 对固定节点交付以 argv 直执行可信命令，证据绑定任务/节点/契约/版本，失败阻止集成；新版本不继承旧结果。最终集成 Runner、沙箱仍待实现。
- **集成与冲突**：`g` 整任务集成 diff；冲突进入独立草稿，只读 AI 顾问解释，人类确认后才改草稿；合并需两次明确确认，带备份与回执，不自动测试/推送/部署。
- **持久化**：SQLite schema 6（任务、消息、契约、尝试、笔记、阅读状态、合并意图）；重启只恢复记录，不恢复执行；单实例锁、符号链接拒绝、删除先备份。
- **配置**：schema 1 分层配置（内置 → 全局 → 项目 → `--config` → CLI），语言（中文/基础英文）、主题、键位、编辑器、Pi 路径/模型与预算可配；配置不授予任何权限。

## 验证状态

- Rust 测试 197 项（单元 + 集成，含真实临时 Git 仓库/PTY 与假 RPC；不调用真实模型）。
- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 干净；GitHub Actions CI 已接入（fmt/clippy/test）。
- Python smoke 脚本 17 个（PTY 端到端），仍为手动运行，未进 CI。
- 已知 flaky：高负载下个别 PTY/时序测试曾整套失败、重跑恢复，待逐个隔离。

## 当前限制

- 英文 UI 仅覆盖核心导航/会话/帮助，工作流弹窗与多数错误仍为中文。
- 节点契约尚无「学习目标」字段；批准前无理解检验；「没看懂」标记与待学清单未实现（路线图见 LEARNING.md）。
- 任意历史节点返工、原 Pi 会话/队列恢复、多 Agent 调度、OS 沙箱均未实现；多 Agent 调度仅有设计文档（docs/multi-agent-scheduling.md），已降级为远期构想，不在当前路线图内。
- Helix 深度嵌入保持现状可用，不再追逐终端按键边角行为。
