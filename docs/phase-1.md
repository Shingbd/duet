## 审核文件入口恢复
修复重启后仅恢复对话、不恢复交付检查点的问题。
- 从最近任务的 checkpoint 重新加载整体 diff 与全部变更文件；“待审 · 文件路径”与主项目基线区分。
- 文件一律读取固定 Git 对象；不因 worktree 后续变化或主项目 HEAD 更新而换成其他内容。
- 待审文件不受基线 80 文件的预览限制；新增、修改、删除均可查看，无法读取明确提示错误。
- 恢复条目后再恢复选中项、已读与滚动状态；重复恢复不重复追加。快照丢失时保留对话并提示恢复失败。
- 新增 :changes 直接打开最新整体变更，[ / ] 浏览变更文件；不自动抢焦点，不合并到主项目。
- 新增 2 项自动回归，总计 48 项通过；测试覆盖超过 80 个新增文件、删除文件、后续可变编辑、HEAD 更新、保存位置与快照缺失。

审核侧栏现在仅显示最近检查点的变更文件，路径不重复，不再有整体“变更”伪文件或“待审 ·”副本。
