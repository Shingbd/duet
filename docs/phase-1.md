# 阶段 1：项目持久化与 AI 编码

## 实际交付
- 去除默认示例文字、模拟任务与定时交付；空界面只有功能分区。
- 普通项目文件夹自动初始化 .duet；SQLite schema 版本 2。
- 笔记、固定版本阅读进度、主题与最近任务对话重启恢复。
- 项目锁、数据路径符号链接拒绝、Git 排除规则与私有权限。
- 用户明确授权后，通过 Pi RPC 在独立 worktree 执行真实编码。
- 读取 message_end 的非空正文保存对话；人工输入即时记录并去除 Pi 回显，流式正文结束后不重复展示。
- 自然 agent_settled 后，主机串行捕获检查点并保留已空闲会话供明确追问；取消或失败时先关闭 Pi 再捕获。退出关闭进程。
- 当前仅单次任务，不是假装完成任务契约或持续多 Agent 调度。

## 自举方式
工作台可以把自身仓库作为 code 的目标。要求已有提交基线；自己的新特性同样在独立 worktree 开发，生成固定检查点，人工验证和接受后再合并。
不允许将自举理解为无人监督的递归改写；不会自动修改主分支或更新正在运行的二进制。

## 验证范围
新增 SQLite 重启、会话/项目隔离、Git 忽略、并发实例锁、符号链接测试。
新增完整假 Pi 流程：发送任务、编辑独立工作区、保存对话、保持源项目脏文件、生成快照、重启恢复任务。
PTY 测试改为真实临时文件夹并核对数据库笔记。
真实模型自举验证与自动回归测试区分记录，不将协议夹具等同于线上调用。

## 交互修复与验证
- 性能：按需重绘、固定文件排版缓存、可见区域渲染、合并输入、SQLite 增量批量保存。详见 docs/performance.md。
- 默认仅小写 j/k，大写 J/K 保留；全屏自动聚焦内容，Tab 返回多面板；底栏明确焦点。
- 对话以结构化角色分块显示，颜色和标题区分“你 / AI”；过滤工具/思考专用空正文，保留原始 Pi 日志和已有数据库证据。
- 新增 p 暂停/继续与 i 纠正/追问。暂停须依次完成清队列、abort 和闲置状态确认，确认失败不标为已暂停。
- 暂停时纠正仅在本地记录，明确继续后才提交。运行中消息使用 streamingBehavior: steer；本轮完成后仍可在同一存活会话追问，并发布新的不可变检查点。
- 对话滚动独立于代码位置；既有代码审阅焦点和快照不被追问覆盖。
- 46 项自动测试通过；debug/release PTY 对话测试、release 导航与终端恢复测试通过；严格 clippy、格式与编译通过。
- 已验证实际安装 Pi 的 clear_queue、abort、get_state 回复格式，全程没有发送模型请求。完整暂停/纠正/继续链路以假 RPC 与真实 PTY 验证，不宣称已完成新的真实模型端到端验证。

## 限制与后续
- 没有任务契约和运行前 diff 审批，使用显式 CLI 授权。
- 不给 Agent bash；项目测试由人类或外部开发工具运行，Runner 待接入。
- cwd 不是访问边界，真实沙箱与限定路径文件工具待实现。
- 当前检查点在单次任务结束后生成；中途人类可以读基线，但真实分阶段审核仍待实现。
- 退出保留 worktree；重启不会自动继续任务。未合并分支不会自动清理。
- 固定快照或差异采集失败时不得宣称交付成功。
- 最近任务可查看恢复对话；同一存活会话支持纠正/追问，但重启不恢复 Pi 执行，多会话导航待实现。
- 没有独立只读讨论会话；运行中/本轮结束后的消息仍可触发编码。暂停时只记录纠正，不会暗中启动模型。
- 后台启动/快照、固定版本验证 Runner、版本审批与受控合并仍待实现。
